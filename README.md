# 🇬🇧 English

## 🚀 Overview

**Oso Barber Booking** is a modern and high-performance web platform designed for managing barber shop appointments in real time.

It focuses on delivering a **fast, clean and intuitive user experience**, allowing clients to book services in seconds while giving administrators full control of the system.

---

## ✨ Main Features

- ⚡ Fast and simple booking system
- 📅 Real-time appointment management
- 💰 Dynamic pricing and promotions
- 👨‍🔧 Barber management system
- 🔍 Reservation search and editing
- 📲 WhatsApp integration
- 📍 Real location and business info
- ⭐ Customer reviews section
- 📸 Real gallery images
- 🎯 Optimized frontend performance

---

## 🖥️ Frontend (Powerful UI)

- Modern and responsive design
- Smooth navigation and fast interactions
- Clean UX focused on quick booking
- Visual branding with real content

### 🏠 Home Page
- Service showcase with prices
- Promotions highlighted
- Direct booking buttons
- Business information (location, hours)
- Social links (WhatsApp / Instagram)

---

## 📅 Booking System

- Select service (cut, beard, combo, etc.)
- Choose available time slots
- Real-time availability
- Book in seconds

---

## 🔍 Reservation Management (Client Side)

- Access **“Mis reservas”**
- Search using name
- View booked appointments
- Reschedule appointments easily

---

## 🧑‍💼 Admin Panel (Advanced)

- Create barbers
- Delete barbers
- Manage reservations
- Search reservations
- Edit booking date and time
- View services and pricing
- Full system control

---

## 🧠 Backend (API Driven)

The system is powered by multiple APIs:

- 🧩 Services API → manages available services and prices
- 👨‍🔧 Barbers API → manages barbers
- 📅 Bookings API → handles reservations
- ⚙️ Admin API → full control of the system

---

## 📍 Real Business Integration

- Location: San Bernardo
- Working hours management
- WhatsApp contact
- Real client reviews
- Real images from the barber shop
